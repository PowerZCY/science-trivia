# Science Trivia Keyword Plan

This document defines keyword targets for the Science Trivia homepage and topic article pages.

The main keyword for the site is:

```txt
science trivia
```

The site should not rely on repeating keywords in `meta keywords`. Google does not use the `meta keywords` tag for ranking, and unnatural repetition can hurt page quality. Keywords should be placed naturally in page titles, meta descriptions, H1/H2 headings, intro paragraphs, article body copy, internal links, archive cards, FAQ sections, and calls to action.

## SEO Positioning

Science Trivia should be positioned as:

```txt
free online science trivia questions with answers and explanations
```

The homepage should target broad quiz intent. Topic articles should target long-tail science questions, topic trivia, and explanation-based searches.

## Homepage Placement

Use the homepage keywords in these areas:

- `title`: include `science trivia questions` and `free online science quiz`
- `description`: include `science trivia questions`, `answers`, `explanations`, and `science facts`
- H1: include `Science Trivia`
- first paragraph: include `science trivia questions` and `science quiz`
- quiz module copy: include `generate science trivia questions`
- archive module: include `biweekly science trivia topics`
- CTA text: include `start a science quiz` or `generate science trivia questions`
- internal links to articles: use topic-specific anchors such as `human body trivia` or `everyday science trivia`

Avoid repeating `science trivia` in every heading. Mix in related phrases so the page reads naturally.

## Topic Article Keyword Strategy

Topic articles should not compete directly with the homepage for the broad `science trivia` keyword. They should target long-tail combinations:

```txt
[topic] trivia
[topic] science questions
[topic] science facts
[topic] quiz questions
why does [phenomenon] happen
how does [phenomenon] work
science behind [everyday thing]
```

Good article pages should include:

- a search-friendly title
- a description that includes the topic and answer value
- an intro that frames the article as science trivia or science facts
- H2 sections around specific questions
- concise explanations that answer real search queries
- a CTA linking back to the homepage quiz

## Keyword Rules

Use this rule for page targeting:

```txt
Homepage = science trivia / science quiz broad keywords
Topic articles = topic + trivia/questions/facts/why/how long-tail keywords
```

Do:

- write for real readers first
- answer specific science questions clearly
- include the target keyword in the title and first paragraph when natural
- use related terms instead of repeating the same exact phrase
- make article descriptions specific enough to earn clicks
- link topic articles back to the homepage quiz

Avoid:

- stuffing `science trivia` into every heading
- creating multiple pages with nearly identical keyword targets
- writing generic articles that do not answer a clear science question
- relying on `meta keywords` as the main SEO tactic
- using article titles that are clever but not searchable
